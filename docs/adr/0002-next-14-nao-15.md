# 0002. Next 14.2, não 15

**Estado:** aceito, 10 de setembro de 2026

## Contexto

A migração precisava de uma versão do Next. A mais recente é a 15, e ela
pressupõe React 19 no App Router.

O `@react-three/fiber` na versão 8, que é a que desenha a mesa, exige React 18.
O suporte a React 19 veio no R3F 9, que traz mudanças de comportamento no ciclo
de vida do canvas. A mesa é a parte do produto mais cara de consertar quando
quebra, porque o defeito aparece como uma tela preta sem erro no console, e já
custou uma investigação longa antes.

## Decisão

Next 14.2 com React 18.3, a mesma versão que o projeto já usava.

## Consequências

O App Router, o `output: standalone` e os route handlers funcionam igual: nada
do que a migração precisa está apenas no 15.

Ficam de fora as novidades do 15, nenhuma delas em uso aqui. O nome de uma opção
mudou entre as versões: em 14 os pacotes que o Node carrega em tempo de execução
ficam em `experimental.serverComponentsExternalPackages`, e não em
`serverExternalPackages`. Custou um build para descobrir.

Subir para o 15 depois é possível, e passa por subir o R3F para 9 e o React para
19 no mesmo movimento, testando a mesa com atenção. Não é urgente.
